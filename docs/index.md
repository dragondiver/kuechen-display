# Küchen-Display

Ein 8-Zoll-Touch mit Raspberry Pi 5, Mikrofonleiste und Kamera in einem Gehäuse im
Braun-Stil, für die offene Küche. Es spricht als Elektra (Repo
[rundfunk](https://github.com/dragondiver/rundfunk)). Code und Issues:
[dragondiver/kuechen-display](https://github.com/dragondiver/kuechen-display).
